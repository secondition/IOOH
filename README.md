# IOOH — I'm out of hotkeys (ZZZ)

IOOH 用角色列表管理绝区零的 3DMigoto Mod，并通过预设保存和切换启用的 Mod。游戏内全局开关负责启用或禁用已加载 Mod 的热键，避免按键冲突。

## 功能

- 按 `Mods/角色/Mod` 展示角色列表、Mod 数量与启用状态；根目录下尚未归类的 Mod 可在角色列表中移动到对应角色。
- 创建、更新和应用预设；切换预设时按 `DISABLED_` 文件夹命名规则启用或禁用 Mod。
- 浏览并修改每个 Mod 的热键；为含热键的 INI 注入游戏内全局开关。
- 在 Mods 目录生成 `IOOHmod.ini`；按下全局开关键时，游戏左下角会显示约 5 秒的状态通知。

## 使用方法

1. 运行发行版，选择游戏使用的 Mods 目录。
2. 在角色列表中管理 Mod；新建预设会保存当前启用的 Mod，应用预设会立即切换文件夹的启用状态。
3. 如需调整热键，点击热键并按下新按键，然后点击「保存并注入」。首次使用时也需要点击一次「保存并注入」，生成游戏内的 `IOOHmod.ini`。
4. 游戏内按小键盘 2 启用或禁用全部已注入的 Mod 热键；可以在侧栏修改全局开关键。

首次注入会在原 INI 旁生成 `.backup` 文件。界面中的「恢复 INI 备份」可恢复原始内容。

## 开发

使用 `pnpm install` 安装依赖，`pnpm start` 启动应用，`pnpm check` 检查代码，`pnpm build` 生成 Windows 便携版。

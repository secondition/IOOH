# IOOH — I'm out of hotkeys(endfield)

IOOH 是一个 3DMigoto mod 的小工具。它能扫描 mod 目录，为每个含热键的 mod 注入全局开关，让你在游戏中用一个键一键启用/禁用所有 mod 热键，解决多 mod 之间的按键冲突问题。

ui比较简陋。。。

## 功能

- 扫描 mod 目录
- 为每个含热键的 mod 注入全局开关变量与开关处理器
- 生成游戏内配置（`IOOHmod.ini`）；每次按下开关键时左下角弹出黄绿通知（与 credits 同一套 help.ini 字体）

## 使用方法

### 1. 下载发行版

### 2. 将exe移动到Mods目录下，创建一个文件夹，将mod文件放入该文件夹中

### 3. 运行exe文件
在弹出的 GUI 中：
1. 选择你的 Mods 目录
2. 点击「扫描并自动配置」
3. 工具会自动完成注入和配置生成

### 4. 游戏内操作

| 按键 | 功能 |
|------|------|
| 小键盘2（可在 GUI 中自定义） | 启用 / 禁用 全部 mod 热键 |

- 按下后所有已注入 mod 的热键一起启用或一起禁用；每次触发都会在左下角弹出黄绿通知（IOOH hotkeys ON/OFF），约 5 秒后消失。
